# Dopafountain

Dopafountain 是一个 Android 随机事实通知器：从互联网权威来源持续筛选“值得高兴、而且有具体事实”的消息，压成一两句话后随机推送。

## V0.2：硬核消息模式

通知不再加入“世界又好了一点”“人类还在探索”等人为语气。规则是：

- 只保留核心事实：谁、做了什么、结果、关键数字/阶段。
- 重点域：科研、医学、航天、工程、能源、生态。
- 来源发现入口限定在 NIH、FDA、Nature、Science、NASA、ESA、WHO、IEA、NOAA 等权威机构/期刊域。
- 使用事实关键词和硬信息特征评分；不够具体就丢弃。
- 没有合格新消息时宁可不通知，不使用励志句或常识性内容补位。
- 每条通知保留来源，点击可打开原文。
- 手机端记录已看 ID，优先推送未看消息。
- 在线失败时只使用最近一次真实互联网缓存，不退回空泛种子消息。

## 数据流水线

GitHub Actions 每 2 小时运行一次：

互联网检索 RSS → 来源限制 → 正向事实筛选 → 去重 → 提取网页摘要（可取到时）→ 中文翻译 → data/goodnews.json

Android App 从公开的 goodnews.json 取水，并按用户设定的平均间隔随机推送。

## Android

- 平均通知间隔：15–90 分钟
- 每次通知后重新随机下一次时间
- 23:00–08:00 静默
- Android 13+ 通知权限
- WorkManager 后台调度
- GitHub Actions 自动构建 Release APK
